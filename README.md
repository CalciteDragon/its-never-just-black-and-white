# Pixel Quest

A pixel-art dungeon platformer: custom physics engine, procedurally generated dungeons, local two-player co-op, and a daily challenge. TypeScript + Canvas API, zero runtime dependencies.

> 🚧 Under construction — full documentation lands with the docs phase. See [docs/GAME-DESIGN.md](docs/GAME-DESIGN.md) for the design spec.

## Quick start

```bash
npm install
npm run dev        # dev server → http://localhost:5173
npm test           # unit tests
npm run build      # production build → dist/
```
